Place Nunito font files here before building:
  - Nunito-Regular.ttf
  - Nunito-Medium.ttf
  - Nunito-SemiBold.ttf
  - Nunito-Bold.ttf

Download from: https://fonts.google.com/specimen/Nunito
Or run: flutter pub add google_fonts  (already included in pubspec.yaml)

Alternatively, remove the fonts section from pubspec.yaml and
the app will use the system default font.
